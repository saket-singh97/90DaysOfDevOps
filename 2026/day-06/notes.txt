Day 06 - file read and write practice
> writes to a file and replaces everything in it
>> adds a new line at the end of the file
cat shows the whole file
head shows the first lines, tail shows the last lines
tail -f is used to watch logs live
logs, configs and scripts are all text files
tee shows the text on screen and also writes it to the file
one wrong > can wipe a whole config file
so use >> when I want to add, not replace

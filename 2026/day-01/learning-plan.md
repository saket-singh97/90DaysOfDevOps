# My 90-Day DevOps Plan

**Current level:** Working professional with hands-on infrastructure ownership at a startup. I started as a WordPress developer and have grown into managing the company's entire technology infrastructure, overseeing all applications and handling their deployment on private VPS infrastructure.

**How I understand DevOps and Cloud:** DevOps combines development and operations to automate software delivery and improve reliability. For me, that means automating the whole path from code to production and live users. Deployment is not only the part of DevOps. A DevOps engineer also keeps an eye on testing, because something that passes in dev can still break in production. They need to understand how the software is built, which framework it uses, and the best way to deploy it, so the role overlaps with development too. A cloud engineer manages the deployment process and the infrastructure behind it.

**Why I'm starting:** I already manage my organization's infrastructure, but at a small scale, and to be honest, not always the right way. I've gained plenty of hands-on experience without ever following a proper process. I want to learn the DevOps workflow and automation properly, from start to finish. I'm also aiming for a better job and a better salary.

**Where I want to reach:** By day 90, I want to be able to take an application from code to a monitored cloud deployment using a proper process, and be ready for a DevOps Engineer role.

## My 3 goals for the next 90 days

1. **Containers and CI/CD:** Get hands-on with Docker, deploy applications on Kubernetes, and build CI/CD pipelines with Jenkins and GitHub Actions.
2. **Cloud and monitoring:** Deploy a 3-tier application on AWS using Terraform, with proper monitoring through Prometheus and Grafana.
3. **Agentic AI:** Understand how AI agents work and how they are being used in DevOps.

## 3 core skills to build in the next 90 days

1. **Linux administration and troubleshooting:** Manage servers confidently and find the root cause when something goes wrong.
2. **CI/CD automation:** Build pipelines with Jenkins and GitHub Actions that take code from commit to production.
3. **Docker, Kubernetes and AWS:** Package applications with Docker, deploy and debug them on Kubernetes, and run them on AWS.

I want to learn all of these tools through real production scenarios, not just tutorials.

## Weekly time budget

- **Weekdays:** 2-3 hours per day
- **Weekends:** 5-6 hours per day
- **Total:** 20-27 hours per week

## How I Will Stay Consistent

* Study and practice daily.
* Make at least one GitHub commit every day.
* Focus on hands-on projects and labs.
* Review progress every weekend.
